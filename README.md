# 🎵 Awaaz Studio — Synced Lyrics & Audio Visualizer

Ek modern, browser-native web application jisse aap bina kisi heavy software (jaise Python ya MoviePy) ke audio-reactive visualizer aur synced lyrics video bana sakte hain.

## 🚀 Live App
Apne browser mein studio chalane ke liye is link par click karein:
👉 **[Open Awaaz Studio](https://azadali15894-stack.github.io/awaaz-studio/)**

---

## ✨ Features
- **Audio-Reactive Visualizers:** 5 cinematic visualizer themes (Bokeh, Rain Drops, Cyberpunk Wave, Bars, Synthwave Grid).
- **Aesthetic Typography:** Stylish fonts aur Unicode fancy text (Gothic, Cursive, Bubble, Double, Sans-Bold).
- **Custom Background:** Apni pasand ki image ya loop video background mein lagane ki suvidha.
- **Synced Lyrics:** Timestamp ke sath lyrics line-by-line chalane ka feature `[mm:ss]`.
- **1-Click Video Export:** Direct `.mp4` / `.webm` format mein video recording aur download.
- **Aspect Ratio:** 16:9 (YouTube) aur 9:16 (Shorts/Reels) dono supported.

---

## 🛠️ Kaise Use Karein
1. **📁 Audio:** Apna song (`.mp3` / `.wav`) upload karein.
2. **🖼️ BG:** Background image ya video select karein.
3. **📝 Lyrics:** Lyrics editor mein jakar samay ke sath lyrics paste karein (e.g., `[00:05] Pehli line`).
4. **🎨 Style:** Font, color, position aur visualizer theme customize karein.
5. **⏺️ Record:** Record button dabakar play karein aur khatam hone par download karein.
